# 🚀 Ignacio Breñas Muñoz — 3D Cyberpunk Portfolio

> **Portfolio web inmersivo de última generación** desarrollado con React 19, TypeScript, Three.js, React Three Fiber, Tailwind CSS y soporte multilenguaje (i18n).

---

## 🌟 Características Destacadas

- ⚡ **Pantalla 404 Glitch de Bienvenida:** Entrada inmersiva simulando un fallo de sistema con efecto glitch CSS de aberración cromática, lluvia de caracteres Matrix y síntesis de audio sci-fi mediante Web Audio API.
- 🌌 **Visualización 3D con Three.js:**
  - **Hero Scene:** Núcleo geométrico flotante en wireframe con luces dinámicas y campo estelar reactivo.
  - **Constelación Orbital 3D en Tech Stack:** Las tecnologías orbitan en anillos concéntricos alrededor de `IGNACIO_CORE`, con soporte para rotación interactiva, zoom orbital e inspección de cada tecnología en un HUD futurista.
- 🌐 **Soporte Multilenguaje Completo (i18n):** Traducción instantánea entre Español (ES) e Inglés (EN) utilizando `i18next` y `react-i18next`.
- 🛡️ **Identidad Visual Personalizada:** Integración del logotipo oficial en barra de navegación, terminal HUD y favicons.
- 📂 **Separación Estricta de Proyectos:**
  - **Proyectos Personales:** Canva Connector MCP, Argus Fraud Radar (UNITA Erasmus+ BIP), Skeleton-Meme (OpenCV/MediaPipe), RunAndEat 2.0 (Laravel 11/Vue.js), DAMA-CRM, Lugia Terminal Setup y Portfolio V1.
  - **Proyectos Académicos:** Más de 20 proyectos desarrollados en STUCOM Pelai clasificados con filtros dinámicos (Java & POO, PHP & Backend, QA & Testing, Desarrollo Web) y buscador en tiempo real.
- 💼 **Trayectoria Profesional & Formación:**
  - Software Developer Intern @ **Soterguard** (TypeScript, Node.js, Python, PostgreSQL, PrismaORM, Docker, LXC, WSL).
  - Técnico Informático en Prácticas @ **VimTech** (Apple Hardware, macOS, Linux).
  - Voluntariado @ **AJMA**.
  - CFGS en Desarrollo de Aplicaciones Web (DAW) & CFGM en Sistemas Microinformáticos y Redes (SMR) en STUCOM Pelai.
- 📬 **Formulario de Contacto & Descarga de CV:** Canales directos, integración con email y enlace para descargar el Currículum Vitae en PDF.

## 💻 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/Ignaciobrenas/ignaciobrenas-portfolio.git

# 2. Entrar al directorio
cd ignaciobrenas-portfolio

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```
